Rama principal: main

Contenido:
  13 pantallas distribuidas en los tres roles del sistema (administrativo,
  docente y acudiente), mas la pantalla de inicio de sesion, construidas a
  partir de las historias de usuario y los casos de uso levantados en las
  evidencias GA2-220501093-AA1-EV02 y GA2-220501093-AA1-EV03.

Como ejecutar el proyecto:
  npm install
  npm run dev
  El sitio queda disponible en http://localhost:3000

Cuentas de demostracion (usuario = contrasena):
  admin      -> panel administrativo
  docente    -> panel del docente
  acudiente  -> portal del acudiente

Nota:
  Las pantallas trabajan con datos de demostracion. La integracion con el
  backend Java corresponde a una actividad posterior del proyecto.
